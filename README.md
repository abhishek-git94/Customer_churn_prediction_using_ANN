# Customer Churn Prediction App

This is a Machine Learning web app built using Streamlit that predicts customer churn.

## Tech Stack
- Python
- TensorFlow
- Scikit-learn
- Streamlit

## Features
- Real-time prediction
- User-friendly UI
- End-to-end ML pipeline

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
